Use `/docs` in the local app for the full onboarding UI and API reference.

Core registration endpoint:

`POST /api/inft/register-agent`

Typical payload fields:

- `agentName`
- `ownerAddress`
- `domainTags`
- `serviceOfferings`
- `modelProvider`
- `systemPrompt`
